# One Line, Big Laugh — v1

One line, one laugh: a warranty that covers water damage gets tested the
worst possible way — by a technician pouring a glass of water over the
laptop to check if it was really broken.

Entry for the make.fun bounty "One Line, Big Laugh". Run `main.py` and it
writes the single entry line to `/output/entry.txt`.
